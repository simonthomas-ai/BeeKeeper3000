Dateien prüfen

Zu jeder Datei steht oben die SHA-256-Prüfsumme. Sie zeigt, dass die Datei vollständig und unverändert angekommen ist. Alle Summen stehen auch in der Datei SHA256SUMS-{{ software.version }}.txt.

Linux und macOS

sha256sum -c SHA256SUMS-{{ software.version }}.txt (macOS: shasum -a 256 -c SHA256SUMS-{{ software.version }}.txt)

Windows (PowerShell)

Get-FileHash -Algorithm SHA256 .\Hornet3000-Setup-{{ software.version }}.exe – das Ergebnis mit der Summe oben vergleichen.

Eine Prüfsumme auf derselben Seite schützt vor Übertragungsfehlern. Sie schützt nicht, falls jemand die Seite selbst verändert hat. Wer das ausschließen will, baut die Software aus dem Quellcode.

Warnmeldungen des Betriebssystems

Windows: Der Installer ist nicht mit einem bezahlten Zertifikat signiert. SmartScreen kann deshalb „Unbekannter Herausgeber“ anzeigen. Prüfen Sie die Prüfsumme, bevor Sie fortfahren.

macOS: Die Programme sind nur selbst signiert und nicht von Apple beglaubigt. Beim ersten Start kann Gatekeeper den Start verweigern. Dann in den Systemeinstellungen unter „Datenschutz & Sicherheit“ den Start ausdrücklich erlauben.

Android: Eine App außerhalb des Play Store braucht die Erlaubnis „Unbekannte Quellen“ bzw. „Installation aus dieser Quelle zulassen“. Das Zertifikat der App hat den SHA-256-Fingerabdruck {{ software.apk_zertifikat_sha256 }} Prüfen lässt er sich mit apksigner verify --print-certs. Android installiert ein Update der App nur, wenn es mit demselben Schlüssel signiert ist.
